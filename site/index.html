How it works

01

Block a site

Add YouTube, Reddit, Twitter — any domain, URL pattern, or keyword. Enable strict mode to lock the settings behind a cooldown.

02

Hit the gate

Navigate to a blocked site. LeetLock intercepts the navigation and presents a clean, focused coding challenge — no ads, no upsells.

03

Solve to unlock

Pass all test cases inside the time limit. LeetLock grants a timed unlock token for that domain. Token expires, gate rearms.

04

Fail the cost

Timeout, exhaust your attempts, or give up — the tab closes or redirects to a calm blocked page. Streak takes the hit.

Built to make the gate real.

2,249+ original problems

Arrays, strings, hash maps, two pointers, sliding window, binary search, stack, heap, math, dynamic programming, linked lists, graphs, trees, backtracking, union-find, and more. Easy, medium, and hard. All original — no LeetCode API. New problems added regularly.

JavaScript, TypeScript + Python

Three languages, one gate. Switch in the editor header. Your choice persists across sessions. TypeScript is transpiled in-browser via sucrase; Python runs via Pyodide — no server, no network request.

Progressive hints

Three-level hints per problem. Each reveal costs 60 seconds off the timer. The friction is intentional — hints should cost something.

CodeMirror 6 editor

Bracket matching, autocomplete, Vim + Emacs keymaps, multi-cursor, rectangular selection, code folding, find/replace, word-wrap toggle, copy-code button, font size, and light + dark mode. Every shortcut in a modal, press ?.

Draft auto-save

Code is saved to local storage with an 800 ms debounce, per-problem, with a 7-day TTL. Refresh or close the tab — your work-in-progress is there when you return.

Submission history

Every Submit is recorded with outcome, test counts, timing, and a snapshot of the code. Restore any submission back to the editor with one click.

Custom test cases

Run any argument combination against your code with the Custom Test drawer — no submission needed, no rate limits, results instantly.

Daily streak tracker

A 12-week activity heatmap in the popup. Streak takes damage on failed challenges, disabled rules, and removed blocks — commitment features should sting.

Settings import / export

Download your block rules, problem prefs, and timing config as JSON. Restore on a new device or share with a study partner.

Why LeetLock

Better than the alternatives.

Site-blockers redirect you away. LeetLock charges you. The distinction matters when your goal is to become a better programmer, not just to avoid Reddit.

  • No login required

    All state lives in chrome.storage. No account, no email, no data harvesting. Open the extension and it works.

  • No ads, no Premium tier

    LeetCode's free experience is a constant upsell funnel. LeetLock has one screen: the problem. Nothing else.

  • Accessible by default

    Every control has aria-label. The verdict panel uses aria-live so screen readers announce results. CodeMirror 6 handles the editor's keyboard navigation correctly out of the box.

  • Honest time limits

    A hard 4-second worker timeout. If your code doesn't terminate, you see it immediately — no noisy "0 ms beats 100%" theater.

  • Zero-hue design

    No green/red/yellow traffic-light UX. Emphasis comes from contrast and typographic weight. Color-blind users are not second-class.

  • Open source, MIT

    The worker, the judge, and every test in the bank are readable on GitHub. No black boxes, no proprietary "algo" behind the scoring.

  • No "show solution" escape

    LeetCode dangles a Solution tab and a Discussion tab. LeetLock has no exit. If you bail, you close the tab — and that's the cost.

  • Tablet-responsive

    Stacks cleanly below 1024 px. Problem panel caps at 45 vh on mobile. LeetCode's layout on a tablet is effectively unusable.

An honest note on limits. Manifest V3 does not allow true anti-uninstall. A determined user can always remove the extension. LeetLock ships friction, not false guarantees — the same way a gym membership works better than a padlock on your fridge.

Commitment features

Make the gate hard to ignore.

Settings cooldown

Strictness-reducing changes (removing a block rule, shortening the time limit) don't apply immediately — they wait out a configurable delay. Regret-proof.

Password lock

Protect settings behind a password hashed with PBKDF2/SHA-256. The plaintext is never stored. Change it on your own terms, not in a moment of weakness.

Accountability partner

Give a trusted person a code. Settings changes require their code to apply. Social accountability, no server required.

Strict mode

Disables Give Up. Locks the settings cooldown. Forces streak damage on any failed challenge. You said you meant it — strict mode makes you.

Two Sum · LeetLock  ·  07:32 remaining
// Given an array of integers nums and an integer target,
// return indices of the two numbers that add up to target.

// Example: nums = [2,7,11,15], target = 9 → [0, 1]

function twoSum(nums, target) {
  const seen = new Map();
  for (let i = 0; i < nums.length; i++) {
    const comp = target - nums[i];
    if (seen.has(comp)) return [seen.get(comp), i];
    seen.set(nums[i], i);
  }
}
